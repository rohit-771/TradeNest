# 📈 TradeNest – Stock Buy/Sell Simulator

## 📌 Description
TradeNest is a simple and responsive web application that displays real-time cryptocurrency data.
It allows users to search, filter, and sort crypto assets while interacting with features like favorites and dark mode.
The project focuses on demonstrating API integration, use of JavaScript Higher Order Functions, and building an interactive user interface.

## 🚀 Features
🔍 Search cryptocurrencies
🎯 Filter (Top 10 coins)
🔽 Sort by price and name
⭐ Favorite button interaction
🌙 Dark/Light mode
📱 Responsive design

## 🌐 API Used
https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd

## 🛠 Tech
HTML, CSS, JavaScript
