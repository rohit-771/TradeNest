# 📈 TradeNest – Stock Buy/Sell Simulator

## 📌 Description
TradeNest is a simple stock trading simulator where users can buy and sell assets using virtual money.

## 🚀 Features
- Fetch real-time stock (crypto) data
- Buy & Sell stocks
- Portfolio tracking
- Search and Sort

## 🌐 API Used
https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd

## 💰 Starting Balance
$10,000

## 🛠 Tech
HTML, CSS, JavaScript
